# API Documentation

Interactive OpenAPI 3 docs are generated by FastAPI at **http://localhost:8000/docs** (raw: `/openapi.json`).
The Power Platform connector subset (Swagger 2.0) is `copilot-studio/connector-openapi.yaml`.

All endpoints except `/health/*`, `/api/v1/auth/dev-token`, `/api/v1/auth/demo-users` and the approval callback
require `Authorization: Bearer <token>`.

## Endpoints

| Method | Path | Permission | Notes |
|---|---|---|---|
| GET | `/health/live`, `/health/ready` | – | readiness checks DB and reports active adapters |
| POST | `/api/v1/auth/dev-token` | – (mock mode only) | `{ "user_id": "u-alice" }` → signed demo token |
| GET | `/api/v1/auth/demo-users` | – (mock mode only) | fictional personas |
| GET | `/api/v1/auth/me` | any | principal + effective permissions |
| POST | `/api/v1/knowledge/query` | knowledge:query | `{ "question": "...", "top_k": 4 }` → answer, citations, `grounded`, `fallback`, `blocked_content_count` |
| GET | `/api/v1/knowledge/documents` | knowledge:query | security-trimmed list |
| POST | `/api/v1/knowledge/ingest` | knowledge:ingest (admin) | incremental (content hash) |
| POST | `/api/v1/tickets` | tickets:create | optional `Idempotency-Key`; 201 |
| GET | `/api/v1/tickets?status=&mine=&limit=&offset=` | tickets:read_own | IT agents see all |
| GET | `/api/v1/tickets/{INCnnnnnnn}` | tickets:read_own | 404 when not visible |
| GET | `/api/v1/tickets/{INCnnnnnnn}/status` | tickets:read_own | lightweight |
| PATCH | `/api/v1/tickets/{INCnnnnnnn}/status` | tickets:update_status, or requester → `cancelled` | state machine, 409 on invalid transition |
| GET | `/api/v1/tickets/{INCnnnnnnn}/history` | tickets:read_own | status events |
| GET | `/api/v1/access/applications` | access:request | catalog (group mapping not exposed) |
| POST | `/api/v1/access-requests` | access:request | **`Idempotency-Key` required**; 201 / 409 / 422 / 503 |
| GET | `/api/v1/access-requests` | access:read_own | IT/admin see all |
| GET | `/api/v1/access-requests/{ACCnnnnnn or id}` | requester, approver, or access:read_all | |
| POST | `/api/v1/access-requests/{ref}/cancel` | requester | only while `pending_approval` |
| POST | `/api/v1/access-requests/{ref}/retry-provisioning` | access:admin | only from `provisioning_failed` |
| GET | `/api/v1/access-requests/{ref}/audit` | same as GET request | audit history of one request |
| GET | `/api/v1/approvals/pending` | approvals:decide | approvals assigned to caller |
| POST | `/api/v1/approvals/{id}/decision` | approvals:decide + assigned approver | mock approval service only |
| POST | `/api/v1/approvals/callback` | `X-Callback-Token` (+ service token with `ITSupport.ApprovalCallback` in Entra mode) | Power Automate |
| POST | `/api/v1/approvals/{id}/simulate-flow-callback` | approvals:decide (mock mode only) | exercises the callback path locally |
| GET | `/api/v1/audit?target_id=&actor_id=&action=` | audit:read | |
| GET | `/api/v1/audit/verify` | audit:read | hash-chain verification |
| GET | `/api/v1/notifications/me` | any | local inbox |
| POST | `/api/v1/agent/chat` | agent:chat | `{ "message", "conversation_id" }` |
| GET | `/api/v1/admin/metrics` | admin:metrics | in-process metrics snapshot |
| GET/POST | `/api/v1/admin/fault-injection` | admin:faults (mock mode only for POST) | simulate outages |
| POST | `/api/v1/admin/maintenance/expire` | access:admin | expire overdue approvals, revoke expired grants |

## Error format

```json
{ "error": { "code": "DUPLICATE_REQUEST", "message": "You already have an active request…",
             "correlation_id": "4f0d0e81…", "details": [{ "request_number": "ACC100001", "status": "pending_approval" }] } }
```

| HTTP | Codes |
|---|---|
| 401 | `UNAUTHENTICATED`, `INVALID_TOKEN`, `TOKEN_EXPIRED`, `INVALID_CALLBACK_TOKEN` |
| 403 | `FORBIDDEN`, `TICKET_UPDATE_FORBIDDEN`, `SELF_APPROVAL_FORBIDDEN`, `NOT_ASSIGNED_APPROVER`, `DIRECT_DECISION_DISABLED`, `CANCEL_FORBIDDEN` |
| 404 | `NOT_FOUND`, `TICKET_NOT_FOUND`, `ACCESS_REQUEST_NOT_FOUND`, `APPROVAL_NOT_FOUND` |
| 409 | `DUPLICATE_REQUEST`, `INVALID_STATUS_TRANSITION`, `APPROVAL_ALREADY_DECIDED`, `APPROVAL_EXPIRED`, `REQUEST_NOT_PENDING`, `NOT_RETRYABLE` |
| 422 | `VALIDATION_FAILED`, `UNKNOWN_APPLICATION`, `UNKNOWN_ROLE`, `DURATION_EXCEEDS_POLICY`, `NO_ELIGIBLE_APPROVER`, `IDEMPOTENCY_KEY_REQUIRED`, `IDEMPOTENCY_KEY_INVALID`, `IDEMPOTENCY_KEY_REUSED` |
| 429 | `RATE_LIMITED` (+ `Retry-After`) |
| 503 | `IDENTITY_PROVIDER_UNAVAILABLE`, `APPROVAL_SERVICE_UNAVAILABLE` |
| 500 | `INTERNAL_ERROR` (no internals leaked) |

## curl walkthrough (mock mode)

```bash
BASE=http://localhost:8000
tok() { curl -s -X POST $BASE/api/v1/auth/dev-token -H 'Content-Type: application/json' -d "{\"user_id\":\"$1\"}" | python -c 'import sys,json;print(json.load(sys.stdin)["access_token"])'; }
ALICE=$(tok u-alice); BOB=$(tok u-bob)

# Knowledge
curl -s -X POST $BASE/api/v1/knowledge/query -H "Authorization: Bearer $ALICE" -H 'Content-Type: application/json' \
  -d '{"question":"How do I install the VPN client on Windows?"}'

# Ticket
curl -s -X POST $BASE/api/v1/tickets -H "Authorization: Bearer $ALICE" -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-ticket-0001' \
  -d '{"title":"Laptop screen flickering","description":"Flickers every few minutes since this morning","category":"hardware","priority":"P3"}'
curl -s $BASE/api/v1/tickets/INC1001001/status -H "Authorization: Bearer $ALICE"

# Access request -> manager approval
curl -s -X POST $BASE/api/v1/access-requests -H "Authorization: Bearer $ALICE" -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-access-0001' \
  -d '{"application_id":"salesforce-crm","role":"read_only","duration_days":30,"justification":"Review Q4 pipeline for the finance forecast"}'
APPROVAL=$(curl -s $BASE/api/v1/approvals/pending -H "Authorization: Bearer $BOB" | python -c 'import sys,json;print(json.load(sys.stdin)[0]["approval"]["id"])')
curl -s -X POST $BASE/api/v1/approvals/$APPROVAL/decision -H "Authorization: Bearer $BOB" -H 'Content-Type: application/json' \
  -d '{"decision":"approve","comment":"OK for Q4"}'

# Agent chat
curl -s -X POST $BASE/api/v1/agent/chat -H "Authorization: Bearer $ALICE" -H 'Content-Type: application/json' \
  -d '{"message":"What is the status of my access requests?"}'
```
